# パス単3級 暗記カード（個人向け Android アプリ）

- 英単語900項目／熟語・表現300項目、全1,200項目。
- カードはPDFの英語・日本語訳を画像のまま保持。OCRから作成した文字データとカタカナ読みは自動生成で、誤認識や不正確な読みが含まれる可能性があります。英語の発音は端末のTextToSpeechを利用します。
- 全範囲・英単語のみ・熟語・表現のみの3モード。Section絞り込み可。
- デフォルトは全範囲＋すべて＋ランダム。モード・学習条件別に出題順と途中の位置を保存。
- 判定は「分かった」「分からなかった」。全モードで結果を共有。
- 苦手リストだけ復習可。復習で「分かった」にした瞬間に苦手リストから外れる。
- 一周を終えたら結果を表示し、次の学習を自分で選べる。
- Android WebViewのローカルStorageに保存。Android版はバックアップJSONの書き出し・読み込み対応。
- ネット接続不要。ただしAndroidの英語TTSデータがインストールされている必要あり。

## ビルド

このファイル自体はAPKではありません。Android SDKが入った環境でビルドします。

### Android Studio
1. このフォルダをAndroid Studioで開く。
2. JDK17、Android SDK Platform 35、Build Tools 35.0.0を用意する。
3. Gradle sync後、`Build > Build Bundle(s) / APK(s) > Build APK(s)` を選択。
4. 生成物は `app/build/outputs/apk/debug/app-debug.apk`。

### GitHub Actions（Android Studio不要）
- リポジトリの`main`ブランチにこのフォルダ一式をアップロード。
- 「Actions」>「Build personal APK」>「Run workflow」。
- Artifactsの`passtan3-offline-debug-apk`をダウンロード、zipを展開してAPKを取り出す。
- 個人端末に初回インストールする際はAndroidの許可操作が必要。

**注意**: 同じ端末に別の署名鍵で作った同パッケージ名のAPKを上書きインストールできません。デバッグAPKの署名鍵はビルド環境ごとに異なるため、更新時は端末側のアプリデータをJSONバックアップしてから再インストールしてください。

## 保存の仕組み

学習データは端末ローカルです。別の端末との自動同期はありません。スマホの再インストールやストレージ削除で消える可能性があるため、定期的なバックアップを推奨します。
